8장. 시맨틱 태그와 접근성

8장 · 01_HTML_기초.docx

div 대신 이름 있는 상자

<!-- 의미가 드러나지 않는 코드 -->
<div class="header">...</div>
<div class="main">...</div>

<!-- 같은 화면, 의미가 드러나는 코드 -->
<header class="header">...</header>
<main class="container">...</main>
header — 머리 부분
nav — 메뉴
section — 주제가 있는 덩어리
main — 페이지의 주요 내용 (한 번만)
aside — 곁다리 정보
footer — 바닥
태그뜻본 교재에서
header머리 부분실습 1-2 상단 바
nav내비게이션 묶음실습 1-2, 2-2
main주요 내용 (한 번만)실습 1-4, 2-3
section주제가 있는 덩어리실습 1-3 히어로, 1-5 기술 스택
footer바닥실습 1-6, 2-8
알아두기 두 코드는 화면상 완전히 같습니다. 차이는 사람과 기계가 읽을 때 생깁니다. 검색 엔진은 main 안의 내용을 본문으로 취급하고, 화면 낭독기 사용자는 nav 나 main 으로 바로 건너뛸 수 있습니다.

접근성 — 최소한 이것만은

  • 모든 img 에 alt 를 씁니다. 장식용이면 alt="" 로 비워 둡니다.
  • 모든 input 에 짝이 되는 label 을 답니다.
  • html 태그에 lang="ko" 를 씁니다.
  • 제목은 h1 → h2 → h3 순서로 건너뛰지 않고 내려갑니다.
  • 색만으로 정보를 전달하지 않습니다. 빨간 글씨에는 문구도 함께 넣습니다.
