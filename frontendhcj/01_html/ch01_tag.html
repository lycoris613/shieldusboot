태그의 생김새

<p class="intro">안녕하세요</p>
 |   |            |          |
 |   |            |          +-- 닫는 태그
 |   |            +------------- 내용(content)
 |   +-------------------------- 속성(attribute)
 +------------------------------ 여는 태그

안녕하세요

이름설명
여는 태그<p> — 여기서부터 시작
닫는 태그</p> — 여기서 끝
요소(element)여는 태그부터 닫는 태그까지 전체
속성(attribute)이름="값" 형태. 여는 태그 안에만

빈 요소 — 닫는 태그가 없는 태그

내용이 없는 태그는 혼자 씁니다.

<br />
<hr />
<img src="..." alt="..." />
<input type="text" name="name" />
<meta charset="UTF-8" />
첫 줄
br 로 줄을 바꿨습니다.
hr 로 구분선을 넣었습니다.
알아두기 끝의 슬래시(/)는 HTML5에서는 없어도 동작합니다. <br> 과 <br /> 은 같습니다.

중첩 — 태그 안에 태그

<div class="card">              <!-- 부모 -->
    <h3>프로젝트 제목</h3>        <!-- 자식 -->
    <p>설명 문구입니다.</p>       <!-- 자식 -->
</div>

프로젝트 제목

설명 문구입니다.

규칙은 하나 — 나중에 연 태그를 먼저 닫는다

<p><strong>굵게</strong></p>      (O)
<p><strong>굵게</p></strong>      (X)  순서가 엇갈림
자주 나는 오류 닫는 태그를 빠뜨리면 그 뒤의 내용이 통째로 그 태그 안으로 빨려 들어갑니다. F12 → Elements 탭에서 실제 구조를 확인하세요.
직접 해보기 위 </div> 를 잠시 지우고 저장해 보세요. 아래 footer 까지 카드 안으로 들어가는 것을 Elements 탭에서 확인할 수 있습니다.

「처음 시작하는 프론트엔드」 기초 문서 예제 · F12를 눌러 개발자 도구를 함께 보세요.
