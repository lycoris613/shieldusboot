7장. div · span 과 class · id

의미 없는 상자 두 개

태그성질쓰임
div블록 — 한 줄을 차지영역을 묶는 상자. 카드, 컨테이너
span인라인 — 글자 흐름 속에문장 속 일부 글자에만 스타일
div — 한 줄 전체를 차지합니다

문장 속의 span 은 흐름을 끊지 않습니다.

class 와 id

<div class="card">...</div>
<div class="card">...</div>       <!-- class 는 여러 번 -->
<form id="studentForm">...</form>  <!-- id 는 단 하나 -->
class="card" ①
class="card" ②
class="card" ③
classid
중복여러 요소가 함께 사용문서 전체에서 단 하나
CSS 선택자.card — 점(.)#studentForm — 샵(#)
주 용도같은 모양을 여러 개에JS 로 하나를 콕 집을 때
알아두기 같은 id 를 두 곳에 쓰면 getElementById 는 첫 번째 것만 찾아내고, 두 번째 요소는 영원히 잡히지 않습니다.

이름 짓기

class="card-image"     (O)  무엇인지를 말함
class="blue-box"       (△)  색을 바꾸면 이름이 거짓말이 됨
class="카드"            (X)  한글
class="card image"     (X)  공백은 두 개의 클래스로 해석됨
자주 나는 오류 class="card image" 로 쓰고 .card image 로 선택하면 안 됩니다. 공백은 "두 개의 클래스"를 뜻하므로 선택자는 .card.image 여야 합니다.
