모든 HTML 파일의 출발점

<!doctype html>
<html lang="ko">
<head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My Portfolio</title>
    <link rel="stylesheet" href="css/style.css" />
</head>
<body>
    <h1>여기부터 화면에 보입니다</h1>
</body>
</html>

위 뼈대만 담은 파일을 따로 만들어 두었습니다 → ch02_minimal.html (CSS: css/ch02.css)

구성역할빠뜨리면
<!doctype html>최신 HTML 문법으로 해석하라고 알림옛날 방식으로 동작해 레이아웃이 어긋남
lang="ko"문서 언어 지정화면 낭독기가 엉뚱하게 읽음
meta charset글자 인코딩한글이 ??? 로 보임
meta viewport모바일에서 실제 크기로 표시휴대폰에서 페이지가 축소됨
<title>브라우저 탭 제목탭에 경로가 그대로 보임
<link>외부 CSS 연결스타일이 하나도 안 먹음

상대 경로

examples/
  |- 01_html/
       |- ch02_structure.html    <-- 지금 이 파일
       |- css/
            |- ch02.css

  href="css/ch02.css"        같은 폴더의 css 폴더 안으로
  href="./css/ch02.css"      위와 같은 뜻 (./ 는 현재 폴더)
  href="../assets/base.css"  한 단계 위로 나간 뒤 assets 폴더로
  href="/assets/base.css"    사이트 최상위 기준 (실습에서는 잘 쓰지 않음)
알아두기 이 페이지가 불러오는 ../assets/base.css 가 바로 "한 단계 위로 나가는" 경로의 실제 예입니다.
자주 나는 오류 CSS 가 전혀 적용되지 않는다면 열에 아홉은 경로 문제입니다. F12 → Network 탭에서 .css 파일이 404 로 나오는지 확인하세요.
확인하기 브라우저 탭에 title 글자가 보이고, 한글이 깨지지 않는다.
미니 과제 ch02_minimal.html 에서 <meta charset="UTF-8" /> 을 잠시 지우고 새로고침해 보세요. 한글이 어떻게 보이나요? (반드시 되돌려 놓으세요)
