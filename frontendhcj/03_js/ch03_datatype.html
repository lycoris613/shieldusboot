템플릿 리터럴 — 백틱 문자열

const url1 = API_BASE_URL + "/api/students/" + id;   // 예전 방식
const url2 = `${API_BASE_URL}/api/students/${id}`;   // 템플릿 리터럴
알아두기 백틱(`)은 키보드 숫자 1 왼쪽, Tab 위에 있는 키입니다. 작은따옴표(')와 다릅니다.
자주 나는 오류 백틱 안에 // 주석을 넣으면 주석이 아니라 그냥 글자가 되어 화면에 그대로 출력됩니다. 실습 3-6에서 실제로 겪는 문제입니다.
