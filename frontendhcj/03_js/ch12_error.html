대표 오류를 직접 발생시켜 보기

각 버튼은 실제로 오류를 일으킨 뒤 try/catch 로 잡아 메시지를 보여줍니다. F12 → Console 에도 함께 찍힙니다.

막혔을 때의 순서

  1. F12 → Console 탭을 연다. 빨간 메시지가 있는지 본다.
  2. 메시지의 파일명과 줄 번호를 클릭해 해당 줄로 간다.
  3. 그 줄에 나오는 변수를 console.log 로 찍어 실제 값을 확인한다.
  4. 서버 통신이면 Network 탭 → Payload 와 Response 를 본다.
  5. 그래도 모르겠으면 오류 메시지를 그대로 검색한다.
가장 흔한 실수 오류 메시지를 읽지 않고 코드를 이리저리 바꿔보는 것입니다. 그러면 원래 맞던 부분까지 망가집니다. 반드시 메시지를 먼저 읽으세요.
