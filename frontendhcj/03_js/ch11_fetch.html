꼭 알아야 할 함정 : response.ok

fetch(url)
    .then((response) => {
        if (!response.ok) {                    // 이 두 줄이 없으면
            throw new Error("불러오기 실패");   // 404 도 성공으로 처리됩니다
        }
        return response.json();
    })
    .then((students) => renderStudentTable(students))
    .catch((error) => console.error("Error:", error));
상황어디서 처리되나
정상 응답 (200)첫 번째 then — response.ok 가 true
404 / 409 / 500첫 번째 then — 직접 throw 해야 catch 로 감
서버가 꺼져 있음catch — Failed to fetch
CORS 차단catch
