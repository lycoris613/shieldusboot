6장. 함수와 화살표 함수

6장 · 03_JavaScript_기초.docx

괄호의 차이 — 아주 중요합니다

loadStudents      // 함수 그 자체를 가리킴
loadStudents()    // 지금 실행하라
자주 나는 오류 addEventListener("click", loadStudents()) 처럼 괄호를 붙이면 등록하는 그 순간 실행되어 버리고, 정작 클릭했을 때는 아무 일도 없습니다.

화살표 함수 — 본 교재에 계속 나오는 그것

function (response) { return response.json(); }   // ① 전통적인 표기
(response) => { return response.json(); }         // ② 화살표 함수
(response) => response.json()                     // ③ 중괄호와 return 생략
규칙설명
매개변수가 하나면괄호 생략 가능 : response => ...
매개변수가 없으면빈 괄호 필요 : () => ...
몸통이 한 줄이면중괄호와 return 을 동시에 생략 가능
중괄호를 쓰면return 을 반드시 직접 써야 함
