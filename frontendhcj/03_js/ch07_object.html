평평한 구조 vs 중첩 구조

// 평평한 구조 (실습 3-5까지)
const studentData = {
    name: "홍길동",
    address: "서울시"
};
studentData.address                  // "서울시"

// 중첩 구조 (실습 3-7부터)
const studentData = {
    name: "홍길동",
    detailRequest: {                 // 객체 안의 객체
        address: "서울시"
    }
};
studentData.detailRequest.address    // "서울시"  — 점을 두 번
studentData.address                  // undefined — 여기엔 없습니다!
자주 나는 오류 데이터 구조를 바꿨는데 검증 코드가 여전히 student.address 를 보고 있으면 undefined 가 나오고, 거기에 다시 점을 찍으면 Cannot read properties of undefined 오류가 납니다.

JSON — 객체를 글자로

JSON.stringify(studentData)   // 객체 → 문자열   (보낼 때)
JSON.parse(text)              // 문자열 → 객체   (받을 때)
response.json()               // 응답 본문을 객체로
알아두기 요청은 detailRequest, 응답은 detail 로 이름이 다릅니다. 서버의 요청용 클래스와 응답용 클래스가 다르기 때문입니다.
