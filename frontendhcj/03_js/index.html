03_JavaScript_기초.docx 예제

각 장마다 HTML 페이지 하나와 JS 파일 하나가 짝을 이룹니다. 모든 페이지에 실행 결과 영역이 있어 개발자 도구를 열지 않아도 결과를 볼 수 있지만, F12 → Console 을 함께 열어두는 것을 권합니다.

알아두기 11장(fetch)은 반드시 Live Server 로 열어야 합니다. 파일을 더블클릭해 열면 file:/// 주소가 되어 fetch 가 차단됩니다.
  • 1장JavaScript 붙이기와 콘솔 — script 위치, console.log / error / table
  • 2장변수 — const 와 let — 재할당, const 객체의 속성 변경
  • 3장자료형과 템플릿 리터럴 — typeof, trim, 백틱과 ${ }
  • 4장연산자 — === vs ==, truthy/falsy, 삼항과 ||
  • 5장조건문과 반복문 — 모드 분기, early return, forEach/for-of/for
  • 6장함수와 화살표 함수 — 괄호의 차이, => 생략 규칙, 콜백
  • 7장객체 — 평평한 구조 vs detailRequest 중첩, JSON
  • 8장배열과 배열 메서드 — forEach, map/filter/find, 표 그리기와 중복
  • 9장DOM — 화면과 대화하기 — 요소 찾기, value, textContent vs innerHTML
  • 10장이벤트 — preventDefault 비교, click/input/change
  • 11장비동기와 fetch — 실행 순서, then 체인, response.ok 함정, POST
  • 12장오류 메시지 읽는 법 — 대표 오류 6종을 직접 발생시켜 보기

JS 만 담은 파일

설명과 데모 상자를 걷어내고 그 장의 js 파일이 동작하는 데 필요한 것만 남긴 파일입니다. 교재용 base.css 를 붙이지 않았으므로 브라우저 기본 모양입니다. JS 는 위의 교재 페이지와 같은 js/ 파일을 함께 씁니다. F12 → Console 을 함께 열어 두세요.

  • 1장ch01_console_only.html — console.log · error · table
  • 2장ch02_variable_only.html — const 재할당 vs 객체 속성 변경
  • 3장ch03_datatype_only.html — 문자열 메서드, 템플릿 리터럴, trim() 과 null
  • 4장ch04_operator_only.html — === 와 ==, truthy/falsy, 삼항 · || · ?.
  • 5장ch05_control_only.html — 모드 전환, early return, 반복문 세 가지
  • 6장ch06_function_only.html — 세 가지 함수 표기, return 누락, 콜백, 괄호 실수
  • 7장ch07_object_only.html — 평평한 구조 vs 중첩, JSON.stringify / parse
  • 8장ch08_array_only.html — forEach, map · filter · find, 표 그리기와 중복
  • 9장ch09_dom_only.html — 요소 찾기, value, textContent vs innerHTML, null 오류
  • 10장ch10_event_only.html — submit 과 preventDefault, input · change · click
  • 11장ch11_fetch_only.html — 실행 순서, GET · POST, 404 와 Failed to fetch
  • 12장ch12_error_only.html — ReferenceError · TypeError · SyntaxError 재현
