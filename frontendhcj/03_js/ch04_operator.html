=== 를 쓰세요

1 === "1"   // false — 값과 자료형이 모두 같아야 참
1 ==  "1"   // true  — 자료형을 맞춰본 뒤 비교 (혼란의 원인)
알아두기 == 는 쓰지 마세요. === 를 쓰면 예상 밖의 결과가 아예 생기지 않습니다.

참 같은 값, 거짓 같은 값

거짓으로 취급 (falsy)나머지는 전부 참 (truthy)
false, 0, "" (빈 문자열), null, undefined, NaN "0", "false", [] (빈 배열), {} (빈 객체) 도 모두 참
자주 나는 오류 빈 배열 [] 은 참입니다. 배열이 비었는지 보려면 list.length === 0 을 써야 합니다.

삼항 연산자와 || 기본값

student.detail ? student.detail.address : "-"     // 삼항 연산자
errorData.message || "학생 등록에 실패했습니다."   // || 기본값
student?.detail?.address ?? "-"                   // 최신 문법
