2장. 변수 — const 와 let

2장 · 03_JavaScript_기초.docx

값에 이름 붙이기

const API_BASE_URL = "http://localhost:8080";   // 바뀌지 않는 값
let editingStudentId = null;                    // 나중에 바뀔 값
키워드재할당언제 쓰나
const불가기본값. 대부분 이것을 씁니다
let가능값이 바뀌어야 할 때만
var가능 (옛날 방식)쓰지 마세요
알아두기 일단 const 로 쓰고, 값을 바꿔야 해서 오류가 나면 그때 let 으로 바꾸세요. "이 값은 안 바뀐다"는 정보가 코드에 그대로 드러나 읽기가 쉬워집니다.

const 인데 내용이 바뀌는 경우

const student = { name: "홍길동" };
student.name = "김코딩";        // OK — 객체의 속성은 바꿀 수 있음
student = { name: "김코딩" };   // 오류 — 변수 자체를 갈아끼우는 것은 불가
