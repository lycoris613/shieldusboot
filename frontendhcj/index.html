  • CSSdisplay 속성 완전 정복 — 7개 장 + 부록 · block/inline부터 flex와 grid까지 (CSS_Flexbox_Grid_가이드_Ver2.docx)

여는 방법

  1. VS Code 에서 student/docs/examples 폴더를 엽니다.
  2. 이 index.html 에서 마우스 오른쪽 → Open with Live Server
  3. 주소가 http://127.0.0.1:5500/... 으로 시작하는지 확인합니다.
주의 파일을 더블클릭해서 열면 주소가 file:/// 로 시작합니다. 대부분의 예제는 그래도 동작하지만, JavaScript 11장(fetch) 은 브라우저가 차단하므로 반드시 Live Server 로 여세요.
알아두기 모든 페이지는 F12 개발자 도구를 함께 열어두고 보는 것을 전제로 만들었습니다. Elements 탭에서 구조와 CSS 를, Console 탭에서 JavaScript 출력을 확인하세요.
