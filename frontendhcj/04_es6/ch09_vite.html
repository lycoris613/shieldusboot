9장. Vite 로 개발 환경 만들기

9장 · 04_ECMAScript_기초.docx

알아두기 이 장은 브라우저가 아니라 터미널에서 따라 하는 실습입니다. Node.js 가 설치되어 있어야 합니다. 아래 명령을 순서대로 입력해 보세요.

0. Node.js 확인

node -v      # v21.7.3   — 버전이 나오면 설치된 것입니다
npm -v       # 10.x
자주 나는 오류 'npm' 은(는) 내부 또는 외부 명령... — Node.js 가 설치되지 않았거나 PATH 에 없습니다. 설치한 뒤 터미널을 새로 여세요.

1. 프로젝트 만들기

npm create vite@latest

Project name:        employee-es6-vite
Select a framework:  Vanilla
Select a variant:    JavaScript

cd employee-es6-vite
npm install
npm run dev
알아두기 Vanilla 를 고르면 React 없이 순수 JavaScript 프로젝트가 만들어집니다. 만들어진 직후에는 node_modules 가 없으므로 반드시 npm install 을 먼저 실행하세요.

2. 폴더 구조와 명령

employee-es6-vite/
  index.html          진입점. Vite 는 여기서 시작한다
  package.json        스크립트와 의존성
  public/             그대로 복사되는 정적 파일
  src/
    main.js           실제 코드의 시작점
    style.css
  vite.config.js      Vite 설정
명령언제 쓰나결과
npm install프로젝트를 처음 받았을 때node_modules 생성
npm run dev개발 중개발 서버 (http://localhost:5173)
npm run build배포 직전dist 폴더에 결과물 생성
npm run preview빌드 결과 확인dist 를 서버처럼 띄운다

3. 환경 변수 — .env 파일

# .env.development   — npm run dev 일 때 사용
VITE_API_URL=http://localhost:8080/api

# .env.production    — npm run build 일 때 사용
VITE_API_URL=https://api.myservice.com/api
// src/main.js
const API_BASE_URL = import.meta.env.VITE_API_URL;

fetch(`${API_BASE_URL}/students`)
    .then(response => response.json())
    .then(students => console.log(students));
자주 나는 오류 import.meta.env.VITE_API_URL 이 undefined — 변수 이름에 VITE_ 접두사가 없거나, .env 파일을 만든 뒤 개발 서버를 다시 시작하지 않았습니다.
알아두기 .env 파일의 값은 빌드 결과물에 그대로 들어갑니다. 비밀번호나 API 키처럼 숨겨야 하는 값은 절대 넣으면 안 됩니다. 그런 값은 서버에서 다뤄야 합니다. .gitignore 에 .env* 를 추가하세요.

이 페이지에서 확인할 수 있는 것

import.meta 자체는 브라우저 표준이라 모듈 안에서 바로 쓸 수 있습니다. 다만 import.meta.env 는 Vite 가 채워 넣는 값이라 여기서는 비어 있습니다.

미니 과제 Vite 프로젝트를 만든 뒤 src/main.js 에 console.log(import.meta.env) 를 넣고 npm run dev 로 열어 보세요. MODE, DEV, VITE_API_URL 이 채워져 있는 것을 볼 수 있습니다.
