# 4부 단계별 코드

교재 `05_ECMAScript_실습_단계별.docx` 의 코드박스 중 **한 페이지를 넘기는 긴 코드**를 파일로 옮겨 둔 것입니다.
문서에서 옮겨 적기 불편할 때 여기서 복사하세요. 각 파일 맨 위 주석에 놓을 위치가 적혀 있습니다.

| 실습 | 파일 | 놓을 위치 |
|---|---|---|
| 4-5 | [`4-5_studentApi.js`](4-5_studentApi.js) | `src/api/studentApi.js` — `request()` 까지 |
| 4-6 | [`4-6_studentApi.js`](4-6_studentApi.js) | `src/api/studentApi.js` — CRUD 까지 (완성본) |
| 4-6 | [`4-6_main_cleanup.js`](4-6_main_cleanup.js) | `src/main.js` — 서버 통신을 studentApi.js 에 넘긴 뒤 |
| 4-7 | [`4-7_studentForm.js`](4-7_studentForm.js) | `src/ui/studentForm.js` — `collectStudentData()` 까지 |
| 4-8 | [`4-8_validation.js`](4-8_validation.js) | `src/lib/validation.js` |
| 4-9 | [`4-9_message.js`](4-9_message.js) | `src/ui/message.js` |
| 4-9 | [`4-9_studentForm.js`](4-9_studentForm.js) | `src/ui/studentForm.js` (완성본) |
| 4-10 | [`4-10_studentTable.js`](4-10_studentTable.js) | `src/ui/studentTable.js` (완성본) |
| 4-11 | [`4-11_main.js`](4-11_main.js) | `src/main.js` (완성본) |

`4-6_main_cleanup.js` 는 그 단계의 중간 상태입니다. 실습 4-11 에서 `4-11_main.js` 로 대체됩니다.

완성된 프로젝트 전체는 `student_ecma/` 폴더에 있습니다.
