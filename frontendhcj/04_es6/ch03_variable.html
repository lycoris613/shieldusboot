3장. 변수 선언 — var, let, const

알아두기 규칙은 두 줄입니다. "var 는 쓰지 않는다. 일단 const 로 쓰고, 값을 바꿔야 해서 오류가 나면 그때 let 으로 바꾼다."

유효 범위 — 함수 스코프 vs 블록 스코프

if (true) {
    var blockVar = "var 로 만든 값";
    let blockLet = "let 으로 만든 값";
}
console.log(blockVar);   // "var 로 만든 값"  — 블록을 무시한다
console.log(blockLet);   // ReferenceError    — 블록 밖에서는 없다

const — 재할당은 막고, 내용 변경은 허용

const student = { name: "홍길동" };
student.name = "김코딩";        // OK   — 속성 변경은 가능
student = { name: "김코딩" };   // TypeError — 통째로 갈아끼우기는 불가

호이스팅과 TDZ

console.log(varAge);   // undefined  — 선언만 끌어올려진다 (오류가 아니다!)
var varAge = 20;

console.log(letAge);   // ReferenceError: Cannot access 'letAge' before initialization
let letAge = 20;       // 선언 전 구간이 TDZ 로 막혀 있다
알아두기 TDZ(Temporal Dead Zone, 일시적 사각지대)는 let/const 가 선언된 줄에 도달하기 전까지 접근이 막혀 있는 구간입니다. let/const 도 호이스팅은 되지만, 값이 채워지기 전에 건드리면 오류를 냅니다. undefined 가 조용히 흘러가는 var 보다 안전합니다.

이 부분은 페이지를 열자마자 자동으로 실행되어 아래 결과 영역에 나옵니다.

차이가 가장 극적으로 드러나는 예

for (var i = 1; i <= 3; i++) {
    setTimeout(() => console.log(i), 100);   // 4, 4, 4
}
for (let j = 1; j <= 3; j++) {
    setTimeout(() => console.log(j), 100);   // 1, 2, 3
}

미니 과제 js/ch03_variable.js 의 마지막 함수에서 var i 를 let i 로 바꿔 보세요. 출력이 4, 4, 4 에서 1, 2, 3 으로 바뀝니다. "반복마다 새 변수가 만들어진다"는 말이 무슨 뜻인지 눈으로 확인할 수 있습니다.
