전개 구문(spread) — 펼치기

const all = [...a, ...b];          // 합치기
const copy = [...a];               // 복사본 (a 와는 다른 배열)
Math.max(...scores);               // 함수 인자로 펼치기

const updated = { ...student, age: 21 };   // age 만 바꾼 새 객체
쓰는 자리이름하는 일예
값을 쓰는 자리전개 (spread)하나를 여러 개로 펼친다 f(...args), [...a], { ...o }
값을 받는 자리나머지 (rest)여러 개를 하나로 모은다 function f(...args), { a, ...rest }
알아두기 뒤에 오는 값이 앞의 값을 덮어씁니다. 그래서 { ...student, age: 21 } 은 "student 를 펼친 뒤 age 만 새 값으로"가 되고, { age: 21, ...student } 는 반대가 됩니다.

위 내용은 페이지를 열자마자 자동으로 실행되어 아래 결과 영역에 나옵니다.

얕은 복사 — 전개 구문은 한 겹만 복사한다

const shallow = { ...origin };
shallow.detailRequest.address = '부산시';   // 원본까지 바뀐다!

// 안쪽까지 새로 만들려면 안쪽도 함께 펼쳐야 한다
const deep = {
    ...origin,
    detailRequest: { ...origin.detailRequest, address: '부산시' }
};

알아두기 React 에서 상태(state)를 바꿀 때 거의 항상 전개 구문을 씁니다. 원본을 직접 고치지 않고 새 객체를 만드는 것이 React 가 "화면을 다시 그릴지"를 판단하는 기준이기 때문입니다.

기본 매개변수(default parameter)

function greet(name = '손님') { ... }

greet();              // '손님'
greet(undefined);     // '손님'   — 안 넘긴 것으로 본다
greet(null);          // null     — 넘긴 값이므로 그대로 쓰인다

// 객체 매개변수 + 구조 분해 + 기본값
function createStudent({ name, age = 20, email = null } = {}) { ... }

자주 나는 오류 Cannot destructure property ... of undefined — 객체를 분해하는 매개변수에 = {} 기본값을 붙이지 않았습니다.
Rest parameter must be last formal parameter — ...args 뒤에 다른 매개변수를 두었습니다.
알아두기 기본값은 오직 undefined 일 때만 적용됩니다. ?? 와 같은 규칙이며 || 와는 다릅니다. 빈 문자열이나 0 을 넘기면 그 값이 그대로 쓰입니다.
미니 과제 js/ch06_spread.js 의 greet 를 ES5 방식(name = name || '손님')으로 바꾼 뒤 greet('') 을 다시 호출해 보세요. 결과가 달라집니다.
