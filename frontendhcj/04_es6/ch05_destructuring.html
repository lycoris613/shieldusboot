객체에서 필요한 값만 꺼내기

const user = {
    name: '둘리',
    age: 30,
    phone: { home: '1234', mobile: '4566' }
};

const { name, age, phone } = user;          // 한 줄로 꺼내기
const { phone: { home, mobile } } = user;   // 안쪽까지 한 번에

const { name: userName } = user;            // 이름 바꿔 받기
const { address = '미입력' } = user;         // 값이 없으면 기본값
알아두기 phone: { home, mobile } 에서 phone 은 변수가 되지 않습니다. "phone 안으로 들어가라"는 길 안내일 뿐입니다. phone 자체도 필요하다면 따로 적어 주어야 합니다.

배열 분해와 매개변수 분해

const [first, second] = ['red', 'green', 'blue'];
const [, , third] = ['red', 'green', 'blue'];   // 건너뛰기

let a = 1, b = 2;
[a, b] = [b, a];                                // 임시 변수 없이 맞바꾸기

// 매개변수 자리에서 바로 분해 — React 에서 자주 보는 형태
function printStudent({ name, studentNumber }) { ... }
알아두기 React 컴포넌트의 function StudentRow({ student, onDelete }) 같은 코드가 바로 이것입니다. props 라는 객체를 통째로 받은 뒤 필요한 것만 매개변수 자리에서 꺼내는 것입니다.

위 내용은 페이지를 열자마자 자동으로 실행되어 아래 결과 영역에 나옵니다.

메서드를 분해하면 this 가 사라진다

const obj = {
    names: 'React',
    greet() { return this.names; }
};

console.log(obj.greet());     // 'React'   — 객체를 통해 부르면 정상

const { names, greet } = obj;
console.log(greet());         // undefined — this 가 obj 가 아니게 됨

const boundGreet = obj.greet.bind(obj);
console.log(boundGreet());    // 'React'   — bind 로 객체를 붙여 주면 해결

자주 나는 오류 Cannot read properties of undefined (reading 'names') — 메서드를 객체에서 떼어 변수나 콜백으로 넘겼습니다. bind() 를 쓰거나 () => obj.greet() 처럼 감싸서 넘기세요.
미니 과제 js/ch05_destructuring.js 의 obj 에 greet3: () => obj.names 를 추가하고 구조 분해로 꺼내 호출해 보세요. this 를 쓰지 않으면 떼어내도 잘 동작한다는 것을 확인할 수 있습니다.
