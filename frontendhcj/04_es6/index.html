문서의 장 번호와 파일 이름을 맞춰 두었습니다. 1장·2장·10장은 개념과 도구 설명이라 실행 예제가 없고, 문법을 다루는 3장부터 9장까지가 실행 가능한 페이지입니다.

주의 7장(Promise)과 8장(모듈)은 반드시 Live Server 로 열어야 합니다. 파일을 더블클릭해 열면 file:/// 주소가 되어 fetch 와 모듈이 모두 차단됩니다.
  • 3장변수 선언 — var, let, const — 블록 스코프, 재선언, 호이스팅과 TDZ
  • 4장템플릿 리터럴과 화살표 함수 — 백틱과 ${ }, => 축약 규칙, this 의 차이
  • 5장구조 분해 할당 — 객체·중첩·배열 분해, 메서드 분해와 bind
  • 6장전개 구문과 그 밖의 문법 — spread / rest, 얕은 복사, 기본 매개변수, ?. 와 ??
  • 7장Promise 와 async / await — 세 가지 상태, 실행 순서, then 체인, Promise.all
  • 8장모듈 — export / import — named / default export, * as, type="module"
  • 9장Vite 로 개발 환경 만들기 — 터미널 실습 안내, .env 와 import.meta

JS 만 담은 파일

설명과 데모 상자를 걷어내고 그 장의 js 파일이 동작하는 데 필요한 것만 남긴 파일입니다. 교재용 base.css 를 붙이지 않았으므로 브라우저 기본 모양입니다. JS 는 위의 교재 페이지와 같은 js/ 파일을 함께 씁니다. F12 → Console 을 함께 열어 두세요.

  • 3장ch03_variable_only.html — var/let 유효 범위·재선언, const, 반복문 + setTimeout
  • 4장ch04_template_arrow_only.html — 화살표 함수와 function 의 this 차이
  • 5장ch05_destructuring_only.html — 메서드를 떼어내면 this 가 사라진다 · bind
  • 6장ch06_spread_only.html — 얕은 복사 함정, rest, 기본 매개변수, ?. 와 ??
  • 7장ch07_async_only.html — Promise 상태, 실행 순서, then · await, Promise.all
  • 8장ch08_module_only.html — export / import — type="module" 필요
  • 9장ch09_vite_only.html — import.meta — type="module" 필요, 버튼 없음
자주 나는 오류 7장은 data/*.json 을 fetch 로 읽고, 8장은 모듈을 import 합니다. 파일을 더블클릭해서 file:// 로 열면 둘 다 CORS 로 막힙니다. 반드시 Live Server 로 여세요.
