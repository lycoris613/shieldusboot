React 기초 예제

06_React_기초.docx · 컴포넌트 · JSX · props/state · Hooks

설치 없이 브라우저에서 바로 돌아갑니다

각 장은 HTML 한 개 + JSX 한 개로 되어 있습니다. npm install 도 node_modules 도 필요 없습니다. Live Server 로 열기만 하면 됩니다.

  • 2장컴포넌트 — 화면을 돌려주는 함수, 대문자 규칙, 프래그먼트, 컴포넌트 트리
  • 3장JSX 란 무엇인가 — createElement 와 나란히 비교, 중괄호, className · style
  • 4장Props 와 State — 값과 함수를 내려 주기, 자식이 부모에게 알리는 법
  • 5장이벤트 핸들링 — 함수를 넘기기 vs 부르기, preventDefault, 위임이 사라진다
  • 6장ref — DOM 다루기 — 포커스와 스크롤, state 와 ref 의 차이
  • 7장컴포넌트 반복 — map() — key 를 id 로 줄 때와 index 로 줄 때를 나란히 비교
  • 8장React Hooks — 같은 컴포넌트를 클래스형과 함수형으로 나란히
  • 9장useState — 불변성, 즉시 반영되지 않음, 입력칸 여럿을 함수 하나로
  • 10장useEffect — [] 와 [값], 정리 함수로 타이머 취소
  • 11장useRef 와 커스텀 훅 — 이전 값·렌더 횟수 기억, useMessage() 만들기

1장(React 라이브러리란)은 개념 설명이라 예제 페이지가 없습니다. 선언형이 무엇인지는 4장에서 직접 확인할 수 있습니다.

어떻게 설치 없이 도는가

각 HTML 은 아래 두 가지로 Vite 가 하던 일을 대신합니다.

Vite 가 하는 일여기서는
node_modules 에서 react 를 찾아 준다 <script type="importmap"> 로 react 를 esm.sh 주소에 연결
JSX 를 JavaScript 로 변환한다 @babel/standalone 이 브라우저에서 변환
알아두기 이 방식은 학습용입니다. Babel 파일이 3MB 라 첫 로딩이 느리고, Console 에 "in-browser transformer" 경고가 뜹니다. 실무에서는 Vite 가 미리 변환해 둡니다 — 그 과정은 06_React기초_실습_단계별.docx 와 student_react_first 프로젝트에서 다룹니다.
자주 나는 오류 파일을 더블클릭해 file:// 로 열면 동작하지 않습니다. Babel 이 js/*.jsx 를 XHR 로 받아오기 때문에 CORS 로 막힙니다. 반드시 Live Server 로 여세요.
확인하기 모든 예제는 React 19.2.0 을 씁니다. student_react_first 프로젝트와 같은 버전이라 여기서 익힌 코드가 그대로 통합니다.

실습 프로젝트로 넘어가기
