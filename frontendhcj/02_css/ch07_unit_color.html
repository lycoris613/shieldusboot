크기 단위

width: 200px — 화면 크기와 무관하게 고정
width: 60% — 부모 너비의 60%
font-size: 1.4rem — html 글자 크기의 1.4배
width: 40vw — 브라우저 창 너비의 40%
height: 15vh — 브라우저 창 높이의 15%

브라우저 창 크기를 바꿔 보세요. px 만 그대로이고 나머지는 함께 변합니다.

단위기준언제 쓰나
px화면의 점 하나테두리, 그림자, 고정 크기
%부모 요소의 크기너비를 부모에 맞출 때
remhtml 의 글자 크기 (보통 16px)글자와 여백 — 가장 권장
em자기 자신의 글자 크기중첩되면 누적되어 헷갈림
vw / vh창 너비 / 높이의 1%화면을 꽉 채우는 영역
fr격자에서 남는 공간의 비율Grid 전용
알아두기 실습 1-3의 height: 60vh 는 "화면 높이의 60%"입니다. px 로 쓰면 화면마다 비율이 달라지지만 vh 는 항상 같은 비율을 차지합니다.

rem 과 em 의 차이

1.2rem — html 기준
1.2rem — 여전히 html 기준 (크기 그대로)
1.2em — 부모 기준
1.2em — 부모가 이미 커졌으므로 더 커짐 (누적)
알아두기 em 은 중첩될수록 값이 곱해져 예측이 어려워집니다. 특별한 이유가 없으면 rem 을 쓰세요.
