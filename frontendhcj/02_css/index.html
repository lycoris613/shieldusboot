02_CSS_기초.docx 예제

각 장마다 HTML 페이지 하나와 CSS 파일 하나가 짝을 이룹니다. css/ 폴더의 CSS 를 직접 고쳐 보면서 화면이 어떻게 바뀌는지 확인하세요.

  • 1장CSS 를 붙이는 세 가지 방법 — 인라인 · 내부 · 외부
  • 2장선택자와 우선순위 — 점과 샵, 공백의 의미, 취소선 읽기
  • 3장박스 모델 — 네 겹 구조, box-sizing 비교, margin auto
  • 4장display — block · inline · inline-block · none
  • 5장Flexbox — justify-content 6가지, align-items, 정중앙 배치
  • 6장CSS Grid — fr, repeat, auto-fit + minmax
  • 7장단위와 색 — px/%/rem/em/vw/vh, hex와 rgba
  • 8장글꼴과 텍스트 — line-height, 시각적 위계
  • 9장배경 · 테두리 · 그림자 — border-radius, box-shadow, overflow
  • 10장position — relative/absolute 한 쌍, sticky
  • 11장transition 과 hover — 평소 상태에 쓰는 이유, 카드 떠오르기
  • 12장반응형과 미디어 쿼리 — viewport, @media, auto-fit 비교

4 · 5 · 6장은 보조자료가 따로 있습니다

display · Flexbox · Grid 는 display 속성 완전 정복 에서 훨씬 깊이 다룹니다. block/inline 의 함정, 주축과 교차축, grid-template-areas, 실전 패턴까지 들어 있습니다.

알아두기 위 1~3장(CSS 붙이는 법 · 선택자 · 박스 모델)을 마쳤다면, 4 · 5 · 6장 대신 보조자료로 넘어가도 됩니다. 돌아와서 7장부터 이어가면 됩니다.

CSS 만 담은 파일

설명과 데모 상자를 걷어내고 그 장의 마크업만 남긴 파일입니다. 교재용 base.css 를 붙이지 않았으므로 브라우저 기본 모양 위에 그 장의 CSS 만 얹혀 있습니다. CSS 는 위의 교재 페이지와 같은 css/ 파일을 함께 씁니다.

  • 1장ch01_three_ways_only.html — 인라인 · 내부 · 외부 세 가지 방식
  • 2장ch02_selector_only.html — 타입/클래스/id, 자손 선택자(공백), 우선순위
  • 3장ch03_boxmodel_only.html — margin/border/padding, box-sizing, margin: 0 auto
  • 4장ch04_display_only.html — block/inline/inline-block, none vs visibility
  • 5장ch05_flexbox_only.html — display:flex, justify-content 6종, align-items 4종, gap
  • 6장ch06_grid_only.html — grid-template-columns, fr, repeat, auto-fit + minmax
  • 7장ch07_unit_color_only.html — px/%/rem/em/vw/vh, 색 이름/hex/rgb/rgba
  • 8장ch08_text_only.html — font-weight, line-height, letter-spacing, text-align
  • 9장ch09_decoration_only.html — border, border-radius, box-shadow, overflow
  • 10장ch10_position_only.html — static/relative/absolute/sticky, top/right
  • 11장ch11_transition_only.html — transition, :hover, transform
  • 12장ch12_responsive_only.html — viewport, @media, auto-fit 비교
