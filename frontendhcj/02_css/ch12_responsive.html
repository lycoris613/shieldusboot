12장. 반응형과 미디어 쿼리

12장 · 02_CSS_기초.docx

먼저 viewport 부터

<meta name="viewport" content="width=device-width, initial-scale=1.0" />

이 한 줄이 head 에 없으면 모바일 브라우저가 페이지를 강제로 축소해 보여줍니다. CSS 를 아무리 잘 짜도 반응형이 동작하지 않습니다.

알아두기 반응형의 출발점은 CSS 가 아니라 이 메타 태그입니다. 이 페이지에도 들어 있으니 소스 보기로 확인해 보세요.

미디어 쿼리

/* 기본 : 넓은 화면 */
.resp { grid-template-columns: repeat(3, 1fr); }

/* 768px 이하 */
@media (max-width: 768px) {
    .resp { grid-template-columns: 1fr; }
}
123

현재 창 너비에 따라 배치가 바뀝니다. 브라우저 창을 좌우로 줄여 보세요.

조건의미흔한 용도
(max-width: 768px)768px 이하태블릿·모바일
(min-width: 1024px)1024px 이상큰 화면 전용
(max-width: 480px)480px 이하작은 휴대폰

미디어 쿼리가 필요 없을 때도 많다
