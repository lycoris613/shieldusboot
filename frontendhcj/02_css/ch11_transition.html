11장. transition 과 hover

11장 · 02_CSS_기초.docx

transition 은 평소 상태에 씁니다

nav a {
    color: white;
    transition: color 0.3s;      /* 평소 상태에 */
}
nav a:hover {
    color: #00adb5;
}
평소 상태에 transition (올릴 때도 뗄 때도 부드러움) :hover 에만 transition (뗄 때 툭 끊김) transition 없음 (즉시 변함)
알아두기 세 링크에 각각 마우스를 올렸다 떼어 보세요. 가운데 링크는 올릴 때만 부드럽고 뗄 때는 툭 끊깁니다.

카드가 떠오르는 효과 — 실습 2-7

.card {
    transition: all 0.3s ease;
}
.card:hover {
    transform: translateY(-10px);
    box-shadow: 0 10px 20px rgba(0, 0, 0, 0.15);
}
