10장 · 02_CSS_기초.docx

relative 와 absolute 는 한 쌍

.card { position: relative; }        /* 기준점 */
.card .badge {
    position: absolute;             /* .card 기준으로 배치 */
    top: 10px;
    right: 10px;
}
NEW 부모에 relative 있음
배지가 카드 오른쪽 위에 붙습니다
NEW 부모에 relative 없음
배지가 페이지 기준으로 날아갑니다
자주 나는 오류 absolute 를 쓸 때 부모에 position: relative 를 빠뜨리면 기준점을 못 찾아 페이지 전체를 기준으로 엉뚱한 곳에 붙습니다. "absolute 자식에는 relative 부모"를 한 쌍으로 기억하세요.

다섯 가지 값

값동작쓰임
static기본값. 문서 흐름 그대로-
relative원래 자리를 유지한 채 조금 이동absolute 자식의 기준점
absolute흐름에서 빠져 relative 부모 기준 배치배지, 닫기 버튼, 툴팁
fixed화면 기준 고정. 스크롤해도 그대로상단 고정 헤더, 채팅 버튼
sticky스크롤하다 특정 위치에서 고정따라오는 목차
