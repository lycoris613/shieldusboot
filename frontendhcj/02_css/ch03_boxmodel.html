네 겹의 구조

+-- margin ------------------------+   <-- 다른 상자와의 거리
|  +-- border --------------------+ |   <-- 테두리 선
|  |  +-- padding -------------+  | |   <-- 내용과 테두리 사이
|  |  |       content          |  | |   <-- 글자, 이미지
|  |  +------------------------+  | |
|  +------------------------------+ |
+----------------------------------+
content

바깥의 연한 영역이 margin, 주황 테두리가 border, 그 안쪽 연두색이 padding, 가운데 흰 부분이 content 입니다.

알아두기 padding 에는 배경색이 칠해지고 margin 에는 칠해지지 않습니다. 이것이 둘을 구분하는 가장 쉬운 방법입니다.

box-sizing — 반드시 알아야 할 한 줄

두 상자 모두 width: 220px; padding: 24px; border: 4px solid; 입니다. 다른 것은 box-sizing 뿐입니다.

box-sizing: content-box (기본값) — 실제 너비 220+48+8 = 276px

content-box

box-sizing: border-box — 실제 너비 그대로 220px

border-box
알아두기 * { box-sizing: border-box; } 를 CSS 맨 위에 한 번 써 두면 이후 모든 계산이 직관적으로 맞아떨어집니다. 실습 1-1이 이것부터 시작하는 이유입니다.

margin: 0 auto — 가로 중앙 정렬

max-width + margin: 0 auto
알아두기 좌우를 auto 로 두면 남는 공간을 좌우가 똑같이 나눠 가집니다. 단, width 나 max-width 가 정해져 있어야 효과가 있습니다.
미니 과제 css/ch03_boxmodel.css 에서 .centered 의 max-width 를 지워 보세요. 중앙 정렬이 사라집니다.
