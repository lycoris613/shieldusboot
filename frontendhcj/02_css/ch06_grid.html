    display: grid;
    grid-template-columns: repeat(3, 1fr);

}

자식이 6개여도 3열이면 자동으로 2줄이 됩니다. 줄바꿈 설정이 필요 없습니다.

fr 단위 — 남는 공간을 비율로

1fr 1fr — 반반

1fr1fr

2fr 1fr — 왼쪽이 두 배

2fr1fr

200px 1fr — 왼쪽 고정, 오른쪽 나머지 전부

200px1fr

auto-fit + minmax — 미디어 쿼리 없는 반응형

grid-template-columns: repeat(auto-fit, minmax(160px, 1fr));
이름학번주소전화번호이메일생년월일

브라우저 창 너비를 좌우로 줄여 보세요. 열 개수가 스스로 줄어듭니다.

부분의미
auto-fit열을 몇 개 만들지 브라우저가 결정
minmax(160px, 1fr)각 열은 최소 160px, 최대는 남는 공간을 나눠 가짐
합친 뜻"한 칸이 160px 보다 작아지면 열 개수를 줄여라"
알아두기 실습 3-3의 .form-grid 가 바로 이 기법입니다. 미디어 쿼리를 한 줄도 쓰지 않았는데 반응형이 됩니다.
