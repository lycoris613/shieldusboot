1장. CSS 를 붙이는 세 가지 방법

1장 · 02_CSS_기초.docx

세 가지 방식

<!-- ① 인라인 : 태그에 직접 -->
<p style="color: red;">빨간 글씨</p>

<!-- ② 내부 : head 안의 style 태그 -->
<style>
    p { color: red; }
</style>

<!-- ③ 외부 : 별도 .css 파일 -->
<link rel="stylesheet" href="css/ch01_three_ways.css" />

① 인라인 — style 속성으로 직접

② 내부 — 이 페이지 head 의 style 태그

③ 외부 — css/ch01_three_ways.css 파일

방식장점단점쓸 때
인라인그 요소에만 확실히재사용 불가, 우선순위가 너무 높음JS 로 값을 바꿀 때만
내부파일 하나로 관리다른 페이지와 공유 불가짧은 실습
외부여러 페이지가 공유파일이 늘어남거의 모든 실무 상황

CSS 규칙의 생김새

선택자 {
    속성: 값;      /* 주석은 이렇게 */
}
자주 나는 오류 세미콜론이나 중괄호를 하나 빠뜨리면 그 지점부터 아래 규칙이 전부 무시됩니다. 브라우저는 오류를 알려주지 않고 그냥 건너뜁니다.
미니 과제 css/ch01_three_ways.css 의 .external-demo 규칙에서 세미콜론 하나를 지우고 저장해 보세요. 그 아래 규칙까지 함께 사라집니다.
