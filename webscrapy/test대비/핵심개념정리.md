## 1. 리스트 / 튜플 / 딕셔너리 / 셋 — 자료형별 특징 비교

### 1-1. 한눈에 비교

| 구분 | 문법 | 가변(Mutable) | 순서 | 중복 | 인덱싱 | 대표 용도 |
|---|---|---|---|---|---|---|
| **리스트 list** | `[1, 2, 3]` | ✅ 가변 | ✅ 있음 | ✅ 허용 | ✅ 가능 | 여러 건의 결과 목록 |
| **튜플 tuple** | `(1, 2, 3)` | ❌ 불변 | ✅ 있음 | ✅ 허용 | ✅ 가능 | 함수의 다중 반환값, 좌표처럼 값이 바뀌면 안 되는 데이터 |
| **딕셔너리 dict** | `{'k': 'v'}` | ✅ 가변 | ✅ 있음(3.7+ 입력 순서 유지) | 키는 불가/값은 가능 | ❌ (키로 조회) | JSON 한 건, 키-값 매핑 |
| **셋 set** | `{1, 2, 3}` | ✅ 가변 | ❌ 없음 | ❌ 불가(자동 제거) | ❌ 불가 | 중복 제거, 교집합/합집합 연산 |

> **주의**: 딕셔너리·셋 모두 `{}`로 시작하지만, `{}`만 쓰면 **빈 딕셔너리**입니다. 빈 셋은 반드시 `set()`으로 만들어야 합니다.

### 1-2. 리스트(list)
```python
fruits = ['사과', '바나나']
fruits.append('포도')        # 맨 뒤에 요소 하나 추가
fruits.extend([1, 2])        # iterable의 요소들을 각각 추가
fruits.insert(0, '수박')     # 특정 위치에 삽입
fruits.remove('바나나')       # 값으로 삭제 (없으면 ValueError)
fruits.pop()                  # 마지막 요소 꺼내며 삭제 (인덱스 지정 가능)
fruits.sort()                 # 원본을 정렬 (반환값 없음, None)
sorted(fruits)                 # 정렬된 "새" 리스트를 반환 (원본 유지)
fruits.index('사과')          # 값의 인덱스 찾기
fruits.count('사과')          # 값의 개수 세기
```
- 인덱싱 `fruits[0]`, 슬라이싱 `fruits[1:3]`, 역순 `fruits[::-1]` 모두 가능.
- **`sort()`(메서드, 원본변경, None 반환)**와 **`sorted()`(내장함수, 새 리스트 반환)** 차이는 자주 출제되는 포인트입니다.

### 1-3. 튜플(tuple)
```python
point = (3, 5)
x, y = point            # 언패킹
point[0] = 10           # ❌ TypeError: 튜플은 값 변경 불가
t = (1,)                 # 요소가 1개인 튜플은 반드시 콤마 필요 (그냥 (1)은 그냥 정수 1)
```
- 함수가 여러 값을 `return a, b`처럼 반환하면 자동으로 튜플로 묶입니다.
- 서로 다른 타입(문자열+숫자 등)을 함께 담을 수 있습니다.
- **불변**이지만, 튜플 안에 리스트가 들어있으면 그 리스트 자체는 수정 가능합니다. (`t = ([1,2], 3)` → `t[0].append(9)`는 가능. 튜플이 막는 건 "슬롯 자체를 다른 객체로 바꾸는 것"이지, 내부 가변 객체의 내용 변경이 아님)

### 1-4. 딕셔너리(dict)
```python
book = {'title': '파이썬'}
book['author'] = '홍길동'          # 추가/수정
book.get('price', 0)                 # 키 없으면 기본값 (KeyError 방지)
book.pop('author')                   # 키로 삭제하며 값 반환
book.keys()   # dict_keys(['title'])   -- 리스트가 아니라 dict_keys 라는 view 객체
book.values() # dict_values([...])
book.items()  # dict_items([...])
'title' in book                       # 키 존재 확인 (in 은 "값"이 아니라 "키" 기준)
```
- `dict.keys()/values()/items()`의 반환 타입은 **리스트가 아니라 view 객체**(`dict_keys`, `dict_values`, `dict_items`)입니다. `list(book.keys())`로 감싸야 진짜 리스트가 됩니다.
- 딕셔너리 컴프리헨션도 가능: `{k: v for k, v in items}`

### 1-5. 셋(set)
```python
a = {1, 2, 3}
b = {2, 3, 4}
a | b   # 합집합 union       -> {1,2,3,4}
a & b   # 교집합 intersection -> {2,3}
a - b   # 차집합 difference   -> {1}
a ^ b   # 대칭차집합 symmetric_difference -> {1,4}
a.add(5)          # 요소 추가
a.discard(10)     # 없어도 에러 없이 삭제 시도 (remove()는 없으면 KeyError)
```
- 순서가 없어서 인덱싱(`a[0]`)이 불가능합니다.
- 셋 안의 요소는 반드시 **불변(hashable)** 객체여야 합니다 — 그래서 `{[1,2], 3}`처럼 리스트를 셋의 원소로 넣으면 TypeError가 납니다.

## 2. pip 연산 총정리

`pip`는 파이썬 패키지(라이브러리) 설치/관리 도구입니다. **pip 자체도 서드파티가 아니라 파이썬에 기본 내장된 패키지 관리자**입니다(단, `requests`, `pandas` 같은 개별 라이브러리는 서드파티).

| 명령어 | 역할 |
|---|---|
| `pip install 패키지명` | PyPI에서 검색해 설치 |
| `pip install 패키지명==1.2.0` | 특정 버전 설치 |
| `pip install --upgrade 패키지명` | 최신 버전으로 업그레이드 |
| `pip uninstall 패키지명` | 삭제 |
| `pip list` | **설치된 모든 패키지 목록** 확인 |
| `pip show 패키지명` | 특정 패키지의 **상세 정보**(버전, 설치 위치, 의존성 등) 확인 |
| `pip freeze` | 설치된 패키지를 `이름==버전` 형식으로 출력 (→ `requirements.txt` 만들 때 사용) |
| `pip install -r requirements.txt` | 파일에 적힌 패키지들을 한 번에 설치 |

> **자주 출제되는 함정**: "설치된 모듈 **목록**을 보려면?" → 정답은 `pip list`. `pip show`는 목록이 아니라 **개별 패키지 하나**의 상세 정보만 보여줍니다.

## 3. 얕은 복사 vs 깊은 복사, 가변/불변 객체

### 3-1. 가변(mutable) vs 불변(immutable) 객체

| 불변(immutable) | 가변(mutable) |
|---|---|
| `int`, `float`, `str`, `tuple`, `bool`, `frozenset` | `list`, `dict`, `set`, 사용자 정의 객체(일반적으로) |

```python
a = "Hello"
b = a
b += " World"
print(a)   # 'Hello' (안 바뀜) — 문자열은 불변이라 b += 는 "새 문자열"을 만들어 b에 재할당한 것
```
```python
x = [1, 2, 3]
y = x            # y는 x와 "같은 리스트"를 가리킴(참조 복사)
y.append(4)
print(x)         # [1, 2, 3, 4] — x도 같이 바뀜! (같은 객체를 참조하기 때문)
```
- `y = x`는 **값 복사가 아니라 참조(주소) 복사**입니다. 리스트/딕셔너리 같은 가변 객체에서 "같이 바뀌는" 문제가 여기서 발생합니다.
- 확인 방법: `id(x) == id(y)` → `True`면 완전히 같은 객체.

### 3-2. 얕은 복사(shallow copy) vs 깊은 복사(deep copy)

```python
import copy

original = [1, 2, [10, 20]]

shallow = original.copy()        # 또는 list(original), original[:]
deep = copy.deepcopy(original)

shallow[0] = 999          # 바깥쪽(1차원) 요소 변경 -> original 영향 없음
print(original)            # [1, 2, [10, 20]]

shallow[2].append(30)     # 안쪽(중첩된) 리스트 변경 -> original도 영향 받음!
print(original)            # [1, 2, [10, 20, 30]]  <- shallow는 내부 리스트까지는 "같은 객체"를 공유

deep[2].append(40)        # deepcopy는 내부까지 통째로 새로 복사했기 때문에 영향 없음
print(original)            # [1, 2, [10, 20, 30]]  <- 그대로
```

| | `y = x` (참조 복사) | `y = x.copy()` (얕은 복사) | `copy.deepcopy(x)` (깊은 복사) |
|---|---|---|---|
| 새 객체 생성 | ❌ 안 함 | ✅ 바깥쪽 1단계만 | ✅ 내부까지 전부 |
| 중첩된 리스트/딕셔너리 | 공유됨 | **공유됨** (함정 포인트) | 완전히 독립 |
| 사용 예 | (거의 사용 X, 실수로 자주 발생) | 단순 리스트 복제 | 중첩 구조를 완전히 분리해야 할 때 |

### 3-3. 함수 기본값(default) 인자의 함정 — "디폴트 vs 파라미터"

```python
def add_item(item, basket=[]):     # ❌ 위험한 패턴
    basket.append(item)
    return basket

print(add_item('사과'))   # ['사과']
print(add_item('바나나')) # ['사과', '바나나']  <- 기대와 다르게 이전 호출 결과가 남아있음!
```
- **이유**: 함수의 기본값(default argument)은 **함수가 정의되는 시점에 딱 한 번만 생성**되고, 이후 호출마다 재사용됩니다. `basket=[]`가 매번 새로 만들어지는 게 아니라 함수 정의 시 만들어진 **하나의 리스트를 계속 재사용**하는 것입니다.
- **올바른 패턴**:
```python
def add_item(item, basket=None):
    if basket is None:
        basket = []       # 호출될 때마다 새 리스트 생성
    basket.append(item)
    return basket
```
- 반면 **전달값(파라미터로 직접 넘긴 값)**은 호출할 때마다 사용자가 새로 넣어주는 것이므로 이 문제가 없습니다. `add_item('사과', [])`처럼 매번 새 리스트를 직접 넘기면 안전합니다.
- **핵심 결론**: 함수 기본값에는 `[]`, `{}`, `set()`처럼 **가변 객체를 직접 쓰지 말고**, `None`을 기본값으로 둔 뒤 함수 안에서 새로 생성하는 것이 정석입니다. (숫자·문자열·튜플처럼 불변 객체는 기본값으로 써도 안전합니다.)

## 4. 내장함수(Built-in Functions) 정리

| 함수 | 설명 | 예시 |
|---|---|---|
| `len(x)` | 길이/요소 개수 | `len([1,2,3])` → 3 |
| `type(x)` | 데이터 타입 확인 | `type(3.5)` → `<class 'float'>` |
| `dir(x)` | 객체가 가진 속성/메서드 목록 | `dir(list)` |
| `id(x)` | 객체의 고유 메모리 주소(식별자) | `id(a) == id(b)`로 같은 객체인지 확인 |
| `isinstance(x, 타입)` | 특정 타입인지 확인(상속 고려) | `isinstance(3, int)` → True |
| `chr(정수)` | 아스키/유니코드 코드 → 문자 | `chr(65)` → `'A'` |
| `ord(문자)` | 문자 → 아스키/유니코드 코드 (`chr`의 반대) | `ord('A')` → 65 |
| `range(start, stop, step)` | 정수 구간 생성(iterable) | `list(range(1,5))` → [1,2,3,4] |
| `enumerate(iterable)` | 인덱스+값을 함께 순회 | `for i, v in enumerate(['a','b'])` |
| `zip(a, b, ...)` | 여러 iterable을 같은 자리끼리 묶음 | `list(zip([1,2],['a','b']))` |
| `map(함수, iterable)` | 각 요소에 함수를 적용한 결과(이터레이터) | `list(map(str, [1,2,3]))` → ['1','2','3'] |
| `filter(함수, iterable)` | 조건(True)에 맞는 요소만 필터링 | `list(filter(lambda x: x%2==0, range(5)))` |
| `sorted(iterable, key=, reverse=)` | 정렬된 **새** 리스트 반환(원본 유지) | `sorted([3,1,2])` → [1,2,3] |
| `sum(iterable)` / `min()` / `max()` | 합계 / 최솟값 / 최댓값 | `sum([1,2,3])` → 6 |
| `abs(x)` | 절댓값 | `abs(-5)` → 5 |
| `round(x, n)` | 반올림(소수점 n자리) | `round(3.14159, 2)` → 3.14 |
| `int()/float()/str()/list()/tuple()/dict()/set()` | 형변환(type casting) | `int('10')` → 10 |
| `input()` | 사용자 입력 받기(항상 문자열로 반환) | `age = int(input())` |
| `open(파일, 모드)` | 파일 열기 | `open('a.txt', 'r')` |
| `print(값, sep=, end=)` | 출력 (`sep`: 구분자, `end`: 끝문자, 기본 `\n`) | `print(1,2,sep='-')` → `1-2` |

> `map()`, `filter()`, `zip()`, `range()`의 결과는 파이썬 3에서는 **바로 리스트가 아니라 이터레이터(iterable)** 이므로, 화면에 값을 보려면 `list(...)`로 감싸야 합니다.

## 5. 라이브러리별 핵심 개념 · 특징 · 주요 연산

### 5-1. Requests — HTTP 요청 라이브러리
**개념**: 파이썬에서 웹 서버에 HTTP 요청(GET/POST 등)을 보내고 응답을 받는 **서드파티** 라이브러리. (`pip install requests` 필요)

**특징**
- 간결한 문법으로 GET/POST/PUT/DELETE 등 모든 HTTP 메서드 지원.
- 쿼리 파라미터(`params`), 헤더(`headers`), 타임아웃(`timeout`) 등을 옵션으로 손쉽게 지정.
- 응답 객체(`Response`)가 상태코드/헤더/본문을 모두 담고 있음.

**주요 연산**
| 코드 | 설명 |
|---|---|
| `requests.get(url, params={...})` | GET 요청, 쿼리스트링 자동 조립 |
| `requests.post(url, data={...})` / `json={...}` | POST 요청(폼데이터 / JSON 바디) |
| `res.status_code` | HTTP 상태 코드 (200=성공, 404=없음, 500=서버오류) |
| `res.text` | 응답 본문을 문자열로 |
| `res.content` | 응답 본문을 바이트(binary)로 (이미지 등) |
| `res.json()` | 응답 본문을 JSON → 딕셔너리로 파싱 |
| `res.headers` | 응답 헤더 |
| `res.raise_for_status()` | 200이 아니면 예외 발생 |
| `requests.get(url, headers={'User-Agent': ...})` | 브라우저인 것처럼 위장(차단 회피) |
| `requests.get(url, verify=False)` | SSL 인증서 검증 무시(보안 위험, 기본값은 `True`) |

### 5-2. BeautifulSoup — HTML/XML 파싱 라이브러리
**개념**: `requests`로 받아온 HTML 문자열에서 원하는 태그·텍스트·속성을 뽑아내는(파싱하는) 라이브러리. (`pip install beautifulsoup4`)

**특징**
- 기본 파서는 `html.parser`(내장). 더 빠른 `lxml` 파서를 쓰려면 **별도 설치**(`pip install lxml`) 필요.
- **CSS 선택자 방식**(`select`, `select_one`)과 **태그/속성 직접 검색 방식**(`find`, `find_all`) 두 가지를 지원.

**주요 연산**
| 코드 | 설명 |
|---|---|
| `BeautifulSoup(html, 'html.parser')` | HTML 문자열을 파싱 가능한 객체로 변환 |
| `soup.select('li.book')` | CSS 선택자로 **여러 개** 찾기 → 리스트 |
| `soup.select_one('li.book')` | CSS 선택자로 **첫 번째 하나만** 찾기 |
| `soup.find('div', class_='quote')` | 태그명+속성으로 첫 번째 요소 찾기 |
| `soup.find_all('a')` | 태그명으로 모든 요소 찾기 → 리스트 |
| `tag.get_text(strip=True)` | 태그 안의 텍스트만 추출(공백 제거) |
| `tag['href']` 또는 `tag.get('href')` | 태그의 속성값 추출 |

> `select()`는 CSS 선택자 문법(`.class`, `#id`, `태그.클래스` 등)을 그대로 쓸 수 있어 실무에서 더 많이 쓰이고, `find()` 계열은 파이썬스러운 인자(`class_=`, `id=`)로 검색합니다.

### 5-3. Pandas — 표 형태 데이터 분석 라이브러리
**개념**: 엑셀 같은 표(행/열) 데이터를 다루는 핵심 라이브러리. `Series`(1차원)와 `DataFrame`(2차원)이 핵심 객체.

**특징**
- '딕셔너리들의 리스트' ↔ `DataFrame`으로 상호 변환이 자유로움.
- 하나의 `DataFrame` 안에서도 **열마다 타입이 다를 수 있음**(문자열 열, 숫자 열 공존 가능).
- 결측치(NaN) 처리, 그룹 집계, 날짜 처리 등 데이터 전처리 기능이 강력함.

**주요 연산**
| 코드 | 설명 |
|---|---|
| `pd.DataFrame(딕셔너리들의리스트)` | 표 생성 |
| `df.shape` / `df.columns` / `df.head(n)` | 행렬크기 / 열이름 / 앞부분 미리보기 |
| `df.describe()` | 숫자 열의 요약 통계(평균/표준편차/사분위수 등) |
| `df['컬럼']` / `df[['컬럼1','컬럼2']]` | 열 선택(단일=Series, 복수=DataFrame) |
| `df['새컬럼'] = 값` | 새 열 추가 |
| `df.loc[조건, 열목록]` | 조건 필터링 + 열 선택을 한번에 |
| `df.sort_values('컬럼', ascending=False)` | 정렬 |
| `df['컬럼'].value_counts()` | 값별 개수 세기 |
| `df.isna().sum()` | 열별 결측치 개수 |
| `df.dropna()` / `df.fillna(값)` | 결측 행 제거 / 결측값 채우기 (`replace`는 결측치 처리 용도가 아님) |
| `df.groupby('컬럼')['다른컬럼'].mean()` | 그룹별 집계 |
| `pd.to_datetime(문자열컬럼, dayfirst=True)` | 문자열 → 날짜형 변환 |
| `df['날짜컬럼'].dt.year` | 날짜에서 연도 추출 |
| `df.to_csv('파일.csv', index=False, encoding='utf-8-sig')` | CSV로 저장 |

### 5-4. Matplotlib — 시각화(그래프) 라이브러리
**개념**: 파이썬에서 세밀하게 커스터마이징 가능한 그래프(plot)를 그리는 기본 시각화 라이브러리.

**특징**
- **Figure**(도화지 전체)와 **Axes**(실제 그래프 영역)로 구조가 나뉨.
- `plt.plot()`(전체 figure에 바로) vs `ax.plot()`(특정 서브플롯에) — 여러 그래프를 배치할 땐 `ax` 방식을 씀.
- 한글 폰트를 별도 설정하지 않으면 한글이 깨짐(□).

**주요 연산**
| 코드 | 설명 |
|---|---|
| `plt.rcParams['font.family'] = 'Malgun Gothic'` | 한글 폰트 설정 |
| `fig, ax = plt.subplots(figsize=(가로,세로))` | Figure+Axes 생성 |
| `fig, axes = plt.subplots(2, 2)` | 2행 2열 여러 그래프 배치 |
| `ax.plot()` / `ax.bar()` / `ax.barh()` | 선 그래프(추세) / 세로막대(비교) / 가로막대 |
| `ax.scatter()` | 산점도(두 값의 관계) |
| `ax.hist(data, bins=n)` | 히스토그램(분포), `bins`는 구간 개수 |
| `ax.pie(sizes, autopct='%1.1f%%')` | 파이차트(비율), `autopct`는 %표시 |
| `ax.set_title()` / `set_xlabel()` / `set_ylabel()` / `legend()` | 제목/축이름/범례 |
| `plt.tight_layout()` | 그래프 간 간격 자동 정리 |
| `fig.savefig('파일.png', dpi=100)` | 이미지 파일로 저장 |

### 5-5. Seaborn — Matplotlib 기반 통계 시각화 라이브러리
**개념**: Matplotlib을 기반으로 더 적은 코드로, 통계적으로 의미있는 그래프를 예쁘게 그려주는 라이브러리. **DataFrame을 바로 입력**받을 수 있는 것이 강점.

**특징**
- `data=df, x='컬럼', y='컬럼'`처럼 컬럼명만 지정하면 자동으로 그래프를 그려줌.
- 테마/팔레트 설정(`sns.set_theme()`)으로 전체 스타일 통일 가능.

**주요 연산**
| 코드 | 설명 |
|---|---|
| `sns.set_theme(style='whitegrid')` | 전체 테마 설정 |
| `sns.barplot(data=df, x=, y=)` | 막대 그래프 |

### 5-6. Selenium — 브라우저 자동화 라이브러리
**개념**: 실제 크롬 브라우저를 코드로 조종해서, `requests`로는 못 가져오는 **JavaScript 렌더링 페이지**(무한스크롤, 로그인 후 화면 등)를 다루는 라이브러리.

**특징**
- Selenium 4.6+ 부터는 `webdriver.Chrome()`만으로 드라이버 자동 관리(수동 다운로드 불필요).
- **Selenium 4에서 `find_element_by_xxx()` 계열 메서드는 삭제**됨 — 반드시 `find_element(By.XXX, ...)` 형태 사용.
- 대기(wait)를 제대로 안 하면 페이지 로딩 전에 요소를 찾아 오류가 남.

**주요 연산**
| 코드 | 설명 |
|---|---|
| `webdriver.Chrome(options=...)` | 브라우저 실행 |
| `driver.get(url)` | 페이지 이동 |
| `driver.find_element(By.CSS_SELECTOR, '값')` | 조건에 맞는 **첫 번째** 요소 하나 |
| `driver.find_elements(By.CSS_SELECTOR, '값')` | 조건에 맞는 **모든** 요소 → 리스트 |
| `elem.click()` / `elem.send_keys('텍스트')` | 클릭 / 텍스트 입력 |
| `driver.implicitly_wait(초)` | 암묵적 대기(모든 탐색에 공통 적용) |
| `WebDriverWait(driver, 초).until(EC.조건)` | 명시적 대기(조건 만족 즉시 진행, 권장) — implicit과 섞어쓰면 안 됨 |
| `driver.save_screenshot('경로')` | 스크린샷 저장 |
| `driver.quit()` | 브라우저 종료(반드시 `finally`에서 호출) |

### 5-7. SQLAlchemy — 파이썬 DB(SQL) 연동 라이브러리
**개념**: 파이썬 코드로 데이터베이스(MySQL, PostgreSQL, SQLite 등)에 연결하고 SQL을 실행하거나, ORM(객체-관계 매핑)으로 테이블을 파이썬 클래스처럼 다룰 수 있게 해주는 라이브러리.

**특징**
- **Core(SQL 직접 실행) 방식**과 **ORM(모델 클래스 기반) 방식** 두 가지 사용법을 지원.
- `create_engine()`으로 DB 연결 정보를 담은 엔진 객체를 만들고, 이 엔진에서 커넥션을 얻어 사용.
- Pandas와 연동이 잘 됨: `pd.read_sql(query, engine)`으로 SQL 결과를 바로 DataFrame으로 받을 수 있음.

**주요 연산**
| 코드 | 설명 |
|---|---|
| `create_engine('sqlite:///data.db')` | DB 연결 정보로 엔진 생성 (드라이버별로 URL 형식 다름) |
| `engine.connect()` | **엔진에서 커넥션을 수동으로 열어** 직접 SQL을 실행할 때 사용 |
| `conn.execute(text('SELECT * FROM users'))` | SQL 실행 (2.0 스타일에서는 `text()`로 감싸는 것을 권장) |
| `pd.read_sql('SELECT * FROM users', engine)` | 쿼리 결과를 DataFrame으로 바로 조회 |
| `df.to_sql('테이블명', engine, if_exists='replace')` | DataFrame을 테이블로 저장 |
| ORM: `Base`, `Session`, `declarative_base()` | 테이블을 파이썬 클래스로 정의하고 객체처럼 다루는 방식 |

## 요약 — 이번 정리에서 특히 헷갈리기 쉬운 포인트 5가지

1. `dict.keys()`의 반환 타입은 리스트가 아니라 **`dict_keys` view 객체**다.
2. `y = x`는 값 복사가 아니라 **참조 복사**라서 리스트/딕셔너리는 원본까지 같이 바뀐다. 문자열/숫자/튜플은 불변이라 안 바뀐다.
3. **얕은 복사는 중첩된 내부 객체까지는 못 막는다** — 완전히 독립시키려면 `copy.deepcopy()`.
4. 함수 기본값에 `[]`/`{}` 같은 가변 객체를 직접 쓰면 **호출마다 재사용되는 함정**이 있다 → `None` 기본값 + 함수 내부 생성이 정석.
5. `pip list`(전체 목록) vs `pip show`(개별 패키지 상세) — 역할이 반대로 자주 출제된다.
