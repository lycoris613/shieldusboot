# shieldusboot

부트캠프 전체 수업자료 모음입니다. 과목별 폴더로 나뉘어 있고, 각 폴더의 예전 개별 저장소 커밋 기록은 이 저장소에 그대로 이어져 있습니다.

| 폴더 | 내용 |
| --- | --- |
| [`backendjava`](backendjava) | 자바 문법 · 객체지향 · 예외 · 컬렉션 · 3계층 설계 실습 |
| [`springfw`](springfw) | Spring Framework 실습 (XML 설정, DI 등) |
| [`springboot`](springboot) | Spring Boot 프로젝트 · 학생 CRUD(1:1, 1:N, 페이징) · 과제 |
| [`frontendhcj`](frontendhcj) | HTML · CSS · JS · ES6 · React 실습과 과제 |
| [`webscrapy`](webscrapy) | 웹 스크래핑 · 데이터 분석과 시각화 노트북 |
| [`vibeantigravity`](vibeantigravity) | Antigravity 기반 바이브 코딩 프로젝트 (biztalk, subagent skills, 웹스크래핑) |
| [`summary`](summary) | 과목별 정리 노트 (BACKEND, FRONTEND, WEBSCRAP, CODETEST, CYBERSECURE) |
| [`llmlangchain`](llmlangchain) | LLM · LangChain 실습 (RAG, Ollama, 챗봇, Tool/Agent, LangGraph) |

## 참고

- `aiml`과 `.idea`는 저장소에 포함하지 않습니다 (루트 `.gitignore`).
- `.env`, `node_modules`, `.venv`, 빌드 산출물은 각 폴더의 `.gitignore`에 따라 제외됩니다.
- 예전 개별 저장소의 일부 브랜치는 태그로 보존했습니다: `archive/springboothw-*`
