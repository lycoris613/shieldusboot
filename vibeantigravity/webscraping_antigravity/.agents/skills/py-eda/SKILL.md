# py-eda: 전문 탐색적 데이터 분석(EDA) 및 시각화 가이드

## 1. 역할 및 환경
- **역할**: 20년차 전문 데이터 분석가 (수석 데이터 사이언티스트)
- **실행 환경**: `antigravity-cli` 기반의 Python 데이터 분석 환경
- **언어 및 어조**: 모든 설명, 분석 내용, 주석, 보고서는 **한국어**로 작성하며, 전문적이고 명확한 분석 인사이트를 제공합니다.

---

## 2. 시각화 공통 규칙 (반드시 준수)

1. **Seaborn 스타일 제한**:
   - `sns.set_style()`, `sns.set_theme()` 등의 전역 스타일 설정은 사용하지 않습니다.
2. **한글 폰트 및 마이너스 기호 설정**:
   - `matplotlib` 기반 시각화 시 한글이 깨지지 않도록 한글 폰트 `Malgun Gothic`을 기본 적용하고, 마이너스 기호 깨짐 방지를 반드시 설정합니다.
   ```python
   import matplotlib.pyplot as plt
   plt.rcParams['font.family'] = 'Malgun Gothic'
   plt.rcParams['axes.unicode_minus'] = False
   ```
3. **이미지 저장 경로 및 명명 규칙**:
   - 모든 시각화 이미지는 해당 프로젝트 디렉토리 내부의 `images/` 폴더에 저장합니다. (폴더가 없으면 자동 생성)
   - 파일명은 시각화 내용을 직관적으로 알 수 있도록 의미 있게 명명합니다. (예: `01_price_distribution.png`, `02_top30_categories.png`)
   - 마크다운 문서 내에서 이미지를 참조할 때는 상대 경로(예: `../images/01_price_distribution.png`)를 사용합니다.

---

## 3. 단계별 EDA 수행 절차

### 1단계: 데이터 기초 파악 (Data Profiling)
데이터셋 로드 직후 다음 항목들을 순서대로 출력 및 파악합니다:
1. **데이터 샘플**: 상위 5개 행(`head(5)`), 하위 5개 행(`tail(5)`) 출력
2. **데이터 스키마 및 메모리**: `info()`로 컬럼별 데이터 타입, Non-Null 수 확인
3. **데이터 크기**: 전체 행과 열의 수(`shape`) 확인
4. **중복 데이터**: 중복 행 수(`df.duplicated().sum()`) 확인
5. **결측치(NaN) 현황**: 컬럼별 결측치 수와 결측 비율(%) 산출
6. **기술통계량**:
   - 수치형 변수: `describe()` (평균, 중위수, 왜도, 사분위수 등)
   - 범주형 변수: `describe(include=['O', 'category'])` (고유값 수, 최빈값, 빈도 등)

### 2단계: 변수별 상세 분석 (Feature Analysis)
1. **범주형 변수 분석**:
   - 범주형 변수는 반드시 빈도수 막대 그래프(Countplot/Bar chart)를 작성합니다.
   - 범주 수가 많을 경우 **상위 30개**만 선별하여 시각화합니다.
2. **텍스트 데이터 분석**:
   - 시간이 오래 걸리는 형태소 분석(KoNLPy 등)은 배제합니다.
   - `scikit-learn`의 **TF-IDF(`TfidfVectorizer`)**를 활용하여 핵심 키워드를 추출합니다.
   - **키워드 빈도수 상위 30개**를 선별하여 가로 막대 그래프로 시각화합니다.
   - 추출된 상위 30개 키워드와 빈도/가중치 점수는 **반드시 표(Table)로도 함께 출력**합니다.

### 3단계: 종합 시각화 및 인사이트 도출 (Comprehensive Visualization)
1. **최소 10개 이상의 시각화 차트 작성**:
   - 일변량(Univariate), 이변량(Bivariate), 다변량(Multivariate) 분석을 다양하게 조합하여 작성합니다.
   - 히스토그램, 박스플롯, 산점도, 히트맵, 누적 막대, 피봇 차트 등 데이터 특성에 최적화된 차트 활용
2. **표(Table) 병행 출력**:
   - 모든 시각화마다 관련된 **교차표(Crosstab), 피봇테이블(Pivot Table), 또는 기술통계표**를 함께 출력합니다.
3. **심층 인사이트 작성 (필수)**:
   - 모든 시각화 결과 아래에는 데이터가 시사하는 핵심 의미와 비즈니스 해석을 담은 **50자 이상의 분석 인사이트**를 반드시 함께 작성합니다.

### 4단계: 통합 리포트 작성 (Reporting)
1. **보고서 파일 생성**:
   - 전체 분석 결과를 프로젝트의 `docs/` 디렉토리에 단일 종합 마크다운 파일(예: `docs/eda_report.md`)로 생성합니다.
2. **보고서 작성 원칙**:
   - 모든 설명과 제목, 분석 내용은 **한국어**로만 작성합니다.
   - 표, 통계 수치, 생성된 시각화 이미지 링크(상대 경로)를 일목요연하게 포함합니다.

### 5단계: 자체 검증 및 개선 (Verification & Refinement)
분석 완료 후 다음 체크리스트를 점검하고 누락이나 미흡한 부분이 있다면 즉시 코드를 보완/재실행합니다:
- [ ] 상위/하위 5개 행, info, shape, 중복값, 결측치, 수치형/범주형 기술통계가 모두 출력되었는가?
- [ ] 범주형 및 텍스트(TF-IDF) 상위 30개 시각화와 표가 포함되었는가?
- [ ] 10개 이상의 다양한 차트가 생성되었고, 각각 50자 이상의 인사이트가 작성되었는가?
- [ ] 모든 차트에 통계표/교차표가 동반되었는가?
- [ ] Seaborn 스타일 설정이 배제되고, 한글 폰트(`Malgun Gothic`)가 정상 적용되었는가?
- [ ] 모든 이미지가 `images/` 폴더에 의미 있는 파일명으로 저장되었는가?
- [ ] 최종 결과가 `docs/` 내의 한국어 마크다운 리포트로 완벽히 정리되었는가?
