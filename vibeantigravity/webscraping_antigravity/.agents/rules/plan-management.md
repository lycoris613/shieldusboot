# Plan 파일 관리 규칙

모든 작업 계획(Plan) 수립 시 다음 규칙을 반드시 준수합니다:

1. **저장 위치**:
   - 모든 Plan 문서는 현재 작업 대상 프로젝트의 `docs/` 폴더 내에 마크다운(`.md`) 파일로 생성 및 저장합니다.
   - 예시: `yes24/docs/plan.md`, `yes24/docs/eda_plan.md`, `project_name/docs/plan.md`

2. **버전 및 이력 관리**:
   - 계획이 수정되거나 추가될 경우에도 해당 `docs/` 경로 내 파일을 직접 갱신하여 사용자가 워크스페이스 내에서 언제든지 확인하고 관리할 수 있도록 합니다.

3. **작성 시기**:
   - 실제 코드 수정이나 실행 전에 `docs/` 경로에 Plan 문서를 먼저 작성하고 사용자에게 안내합니다.
